本地模型安装向导

本地模型要跑起来需要两样东西：Ollama（跑模型的宿主程序，约 1.5 GB）和一个模型文件（约 4.7 GB）。 这个向导会替你全部装好，不用记任何命令。中途可以随时关窗，下次接着来。

想跳过这些？本地模型的好处是断网可用、聊天内容不出本机；如果你更在意"开箱即用"， 随时可以在托盘菜单 → 切换聊天大脑里改用云端接口（只需填一个 API Key，无需下载任何东西）。
