装 Ollama、拉模型、起服务，以前全要自己在终端里敲 —— 现在应用里点一下就走完。

✦一句话更新

  • 装 Ollama 不用再敲命令 —— 应用里新增「本地模型安装向导」，点一下自动下载、自动装好。
  • 模型也不用自己去拉 —— 向导里选一档大小（7B / 3B / 1.5B），点下载就行。
  • 国内网络也下得动 —— 内置 4 条下载源（含国内镜像），开下之前先探活、挑最快的那条，失败自动换下一条。
  • 装它不需要管理员权限 —— 静默安装走"每用户安装"，不弹 UAC、不写 Program Files。
  • 进度看得见、随时能停 —— 显示百分比 / 已下体积 / 实时速度 / 剩余时间，可取消；断了下次接着下。
  • 不会把坏包装上 —— 下载完成先比对官方 sha256 指纹，不一致就重下。
  • 入口好找 —— 托盘菜单多了一项「本地模型安装向导…」；选择大脑窗里「本地模型」那张卡片上也有按钮。
  • 该提醒的都会提醒 —— 磁盘空间不够、服务没起来、下载失败，都在当场写清原因和下一步。
  • （修复）安装包不再把开发机上的设置带给别人 —— 私人配置已排除在包外，使用者首启走干净的默认状态。
  • （修复）新用户不再只看到一句"请先安装 Ollama" —— 那句话现在变成了一个点得动的按钮。

◆新增内容

本地模型安装向导核心

以前想用本地模型，得自己去 Ollama 官网下载、装好、再回到终端敲 ollama pull 拉一个 4.7 GB 的模型 —— 三道门槛全压在新用户身上，任何一步卡住都只能放弃。现在整条链子做成了一个向导：

① 环境检测② 安装 Ollama③ 启动服务 ④ 下载模型⑤ 启用

每一步都能单独重来，中途关掉窗口也不影响，下次打开接着走。界面上的检测结果是 实时读你机器上的真实状态：程序装没装、服务在不在跑、模型有没有下好、 放在哪个目录、那个盘还剩多少空间。

下载源自动择优

Ollama 的安装包托管在 GitHub 上，国内直连经常不通（官方地址本身也会跳转过去）。 向导内置了 4 条下载源，开下之前并发探活一次，按实测延迟排序后从最快的一条开始下， 中途断了就自动换下一条。四条全不通时，会给你一个「用浏览器手动下载」的按钮 （浏览器走系统代理，往往比程序内更容易连上）。

静默安装，不打扰

安装过程完全静默：不弹 UAC、不需要管理员权限、不会往桌面上塞快捷方式。 装完会自动等程序就位，再进入下一步。

拉模型带完整进度

下载模型时显示百分比、已下载体积、实时速度、剩余时间。 点「取消」立刻停（不会在后台偷偷继续下），已下载的部分会保留，再点开始就接着下。

完整性校验

下载完成后比对该版本的官方 sha256 指纹，不一致就判定为下载不完整并让你重试 —— 避免"装到一半的包"被当成装好了，那种问题事后极难排查。

◇优化调整

  • 选择大脑窗：探测本机环境失败时，原来只有一句纯文字提示，现在直接给出可点的入口 （没装 → 「一键安装 Ollama」；装了但没模型 → 「一键下载模型」）。
  • 托盘菜单：新增「本地模型安装向导…」，随时可以回来重跑或换别的模型。
  • 自动刷新：向导装好后，正开着的大脑选择窗会自动重新检测，不用手动关掉重开。

▲问题修复

重点是这两条
  • 安装包会把开发机的私人设置带给使用者。 你在自己机器上调好的配置（本机模型路径、屏幕追踪选的是第几块屏等）以前会被一起打进安装包 —— 朋友装完打开可能是一片空白，或者直接进本地模型却发现根本没装 Ollama、 还不知道去哪儿改。现在配置不再进包，使用者首启会从干净的默认状态开始 （默认云端 + 弹出选择窗）。
  • 新用户的门槛。原来检测不到 Ollama 时只提示 "请先安装 Ollama / 请执行 ollama pull xxx"，等于把最难的一步原样丢回去。现在是一个按钮。

!使用须知

  • 安装包仍然不含 Ollama，也不含模型。安装包约 266 MB；Ollama 安装包本身 1.5 GB， 一个 7B 模型约 4.7 GB —— 都塞进来会变成 7.4 GB 左右，而且用不上的显卡后端也得跟着下。 需要的话由向导按需下载。
  • 需要联网：装 Ollama 约 1.5 GB、拉模型约 4.7 GB（选更小的档能省不少）。
  • 显存参考：7B（4.7 GB）需约 5~6 GB 显存；6 GB 以下建议选 3B；核显 / 小内存选 1.5B。
  • 第一次回复会慢：模型要加载进显存，约 30~60 秒；之后就都是毫秒级了。
  • 随时可以换：托盘菜单 →「切换聊天大脑」，本地 / 云端 / WorkBuddy 随便切； 本地模型不占用时不会常驻，退出桌宠会一起关掉（但不会关你自己开着的那个）。
  • 不想装这些？云端接口只需要填一个 API Key，什么都不用下载 —— 这也是首启默认选它的原因。
