# IndexTTS-2 安装 · 手把手详细版

> 这份是给"不熟悉命令行"的情况写的。你**不需要手打任何命令**，只要双击两个文件。
> 想看技术细节就看另一份 `index_tts_setup.md`，日常照这份做就行。
>
> **2026-09-18 修订**：官方仓库升级了依赖管理方式（改用 `uv`，**不再有 `requirements.txt`**），
> 安装步骤与判断标准已按新版更新。

---

## 0. 先搞清楚一件事：我不用你输命令

之前那份文档里那些 `set PY=...`、`%PY% -m pip install ...` 是"命令提示符"里才用的语法，
看起来确实费劲。所以我把它们**全部打包成了两个 `.cmd` 脚本**，你双击就行。

| 文件（都在 `D:\live2d-companion\tts\` 里） | 作用 | 什么时候用 |
|---|---|---|
| **`setup_index_tts.cmd`** | 自动装好 IndexTTS-2（含下载约 10GB 模型） | 第一次，只跑一次 |
| **`try_voice.cmd`** | 用你的音色生成一句话试听 | 装完之后，随时 |

> 顺带解释一下那几个词，以后看到不慌：
> - **pip** 是 Python 的"应用商店"，`pip install xxx` = 安装某个库。
> - **uv** 是新式的"环境+应用商店"，它会把一个项目用到的所有库装进项目自己的小房间（`.venv`），
>   不碰你系统里的 Python。IndexTTS-2 现在就是用它。
> - **git** 是"代码下载器"，`git clone` = 把某个开源项目的代码拉下来。
> 这几个动作脚本里都替你做了。

## 1. 跑之前：先腾出显存 ⚠️

我体检时发现显卡**已被占用 6.9 GB**（只剩约 5.1 GB）。IndexTTS-2 推理需要 6–8 GB。

**请先关掉占显卡的程序**：浏览器（尤其多标签页）、游戏、其他 AI 工具、视频编辑软件。
不确定的话，跑之前关掉浏览器就够了。

---

## 2. 第一步：双击 `setup_index_tts.cmd`

打开文件资源管理器，进到：

```
D:\live2d-companion\tts\
```

找到 **`setup_index_tts.cmd`**，**双击**它。

### 会看到什么

弹出一个黑窗口，显示 5 个步骤。每一行英文都很直白：

```
[1/5] checking python ...          <- 检查 Python 能不能用
[2/5] installing uv ...            <- 装 uv（这个项目现在用它管理依赖）
[3/5] getting the repo ...         <- 下载 / 更新 IndexTTS-2 的代码
[4/5] creating the python environment (uv sync ...)   <- 建 .venv 并装依赖（含 CUDA 版 PyTorch，几 GB）
[5/5] downloading model weights ...<- 下载模型权重（约 10GB，最慢的一步）
```

### 注意三点

1. **开头会停一次**，显示 `Press any key to continue` —— 按一下空格或回车即可。
2. **第 4、5 步都慢**：第 4 步要下几个 GB 的 PyTorch，第 5 步约 10 GB。**窗口千万别关。**
   中断了也没关系，**重新双击脚本会接着下**（已经有文件会跳过）。
3. 如果弹出 Windows 的"未知发布者 / SmartScreen"提示，点 **「仍要运行」**（这是你自己做的脚本）。

### 成功 / 失败

- 最后看到 **`DONE`** 就成功了。权重在：
  ```
  D:\index-tts\checkpoints_2
  ```
  （**注意是 `checkpoints_2`**：官方规定 IndexTTS-2 放在 `checkpoints_2`，
  另一款 IndexTTS-2.5 才放在 `checkpoints`。）
- 如果看到 **`FAILED`**，说明某一步出错。**把黑窗口里最后几行文字复制（或截图）发给我**，我来判断。

## 3. 第二步：双击 `try_voice.cmd` 试听

装完后再回到 `D:\live2d-companion\tts\`，这次双击 **`try_voice.cmd`**。

它会用你录的那段声音，说一句"前辈，今天的海水样本送到了……"，输出到：

```
D:\live2d-companion\tts\_out\sample_indextts.wav
```

看到 `DONE` 之后，去那个目录**双击 wav 文件**就能播放。

> **第一次会很久**（要加载模型 + 下载几个"辅助模型"，合计约 5GB，可能需要 5–30 分钟），
> 之后每句只要几秒。辅助模型只需要下一次，之后就不再下了。

### ⚠️ 第一次可能卡住的地方（我已经替你处理好）

初次推理时它会去下 4 个辅助模型，其中 3 个走国内的 ModelScope（很快），
但**声码器 `bigvgan_generator.pt`（428MB）国内没有镜像**，会去 HuggingFace 的 CDN 拿，
速度只有 ~76KB/s，还容易**卡死不动**（表现为文件停在几百 KB 十几分钟不变）。

我已经用 8 路并行把它下好了。**万一将来重装又卡在这里**，手工执行这个（PowerShell 窗口里粘贴即可）：

```powershell
$dir = 'D:\index-tts\_chunk'
New-Item -ItemType Directory -Force -Path $dir | Out-Null
$url = 'https://hf-mirror.com/nvidia/bigvgan_v2_22khz_80band_256x/resolve/main/bigvgan_generator.pt'
$total = 449228171; $n = 8; $chunk = [math]::Ceiling($total / $n)
$ps = @()
for ($i = 0; $i -lt $n; $i++) {
  $s = $i * $chunk; $e = [math]::Min(($i + 1) * $chunk - 1, $total - 1)
  $ps += Start-Process curl.exe -ArgumentList @('-sL','--noproxy','*','--retry','30','--retry-delay','3','--retry-all-errors','-r',"$s-$e",'-o',"$dir\c$i.bin",$url) -NoNewWindow -PassThru
}
$ps | ForEach-Object { $_.WaitForExit() }
$out = 'D:\index-tts\checkpoints_2\hf_cache\bigvgan\bigvgan_generator.pt'
$fs = [IO.File]::Create($out)
for ($i = 0; $i -lt $n; $i++) {
  $b = [IO.File]::ReadAllBytes("$dir\c$i.bin"); $fs.Write($b, 0, $b.Length)
}
$fs.Close(); Remove-Item $dir -Recurse -Force
"written: " + (Get-Item $out).Length
```

完成后那个文件的正确大小是 **449,228,171 字节**。

**听着不满意可以调**（改 `try_voice.cmd`，右键 → 编辑，用记事本打开）：

| 想要的效果 | 改哪一行 | 建议范围 |
|---|---|---|
| 声音更像少年（音调更高） | `INDEXTTS_SEMITONES=2.5` | 1.5 ~ 3.5 |
| 声音更接近原音（音调更低） | 同上，改小 | 0 ~ 1.5 |
| 语气更强烈 | `INDEXTTS_EMO_ALPHA=0.85` | 0.6 ~ 0.9 |
| 语气更平淡 | 同上，改小 | 0.3 ~ 0.6 |
| 完全不要少年化 | `INDEXTTS_BOYIFY=1` 改成 `0` | — |

## 4. 第三步：让它接到桌宠上

试听满意后，把桌宠接上它。用**记事本**打开：

```
D:\live2d-companion\app\config.json
```

改三个地方（其他别动）：

| 键 | 改成 | 说明 |
|---|---|---|
| `"ttsEngine"` | `"indextts"` | 指定用 IndexTTS-2 |
| `"ttsPython"` | `"D:\\index-tts\\.venv\\Scripts\\python.exe"` | **必须指到这个 .venv 里的 python** |
| `"indexttsDir"` | `"D:\\index-tts"` | 仓库根目录 |

> `ttsPython` 是个**关键坑**：IndexTTS-2 的依赖（含 PyTorch）装在 `uv` 建的那个"小房间"
> `.venv` 里，不指到它，侧车会去用系统 Python，结果是"引擎装了却显示不可用"。
>
> 反斜杠要写**两个** `\\`（JSON 的写法要求）。直接复制上面表格里的内容最省事。

保存后，**双击 `start.cmd` 重启桌宠**。之后挂机/点击台词就会用你的声音说话了。

想确认引擎有没有认到，可以看 `app.log`，搜 `tts:` 开头的行，应该能看到 `active=indextts`。

## 5. 名词小抄

| 词 | 人话解释 |
|---|---|
| **命令提示符 / cmd** | Windows 里输命令的黑窗口。按 `Win + R`，输入 `cmd`，回车就能打开。这次你用不到。 |
| **pip** | Python 的应用商店 |
| **uv** | 新式的项目环境管理器。`uv sync` = 按项目清单把依赖装进它自己的 `.venv`。 |
| **.venv** | 项目专属的"库房间"，跟系统 Python 隔离，互不干扰。 |
| **git** | 代码下载器（你机器上已经装好了） |
| **环境变量** | 给程序看的"配置纸条"。这次不用你设——已经改成从 `config.json` 读了。 |
| **显存** | 显卡上的内存。跑大模型主要吃这个。 |
| **权重** | 模型的"大脑文件"，就是那 10GB。 |

## 6. 已经踩过的坑（供参考）

| 现象 | 原因 | 处理 |
|---|---|---|
| `ERROR: Could not open requirements file: ... requirements.txt` | 官方仓库**已删除** `requirements.txt`，改用 `pyproject.toml` + `uv.lock` | 新版脚本已改为 `uv sync`，不会再报这个 |
| 引擎显示 `available=False`，但模型确实下了 | `ttsPython` 没指到 `.venv` 里的 python | 按第 4 节改成 `D:\\index-tts\\.venv\\Scripts\\python.exe` |
| 提示显存不足 / `CUDA out of memory` | 显存被别的程序占了 | 关掉浏览器/游戏/其他 AI 工具后重启桌宠 |
| 权重下载中断 | 网络 | 重新双击 `setup_index_tts.cmd`，会接着下 |

---

## 7. 卡住了怎么办

按这个顺序：

1. **把黑窗口最后 5~10 行文字复制给我**（或截图）。这是排查最快的办法。
2. 如果是第 5 步下载中断/很慢：网络问题居多，重新双击脚本即可续传/重试。
3. 别的都试过还不行：把 `python tts\env_check.py` 的输出发我，我看看缺什么。
